# 《小国执政官》游戏说明

> 一份给玩家与产品/运营同学的玩法说明文档。技术与数值细节请见 [`策划案_v2.md`](./策划案_v2.md)。

---

## 一、你扮演谁？

你是一个新上任的**执政官**，被派去治理一座只有 25 个人左右的小国。
你的任务是：通过调税、用人、应对突发事件，让这个国家在风雨中**活下去并繁荣**。

---

## 二、一年里你做什么？

每一年（一个回合），你会经历三个阶段：

### 1️⃣ 决策阶段 —— 你说了算
左边「政策调控」面板可以设置：
- **税率**：分别针对农民 / 工人 / 商人，0%~50%
- **公务员配额**：把有限的公务员分配到税务、治安、民生、军事、教师 5 个岗位
- **军费比例**：每年从国库拿出多少做军事开支

### 2️⃣ 结算阶段 —— 自动模拟
点"⏯ 下一年"按钮，系统会按以下顺序自动模拟：

```
分配公务员岗位 → 农民种地 → 工人造产品 → 商人撮合交易
→ 政府征税 → 发工资 → 军费支出 → 教师授课 → 全民消费
→ 计算满意度 → 判断罪犯 → 罪犯掠夺 → 生育 → 老化死亡 → 阶级流动
```

### 3️⃣ 反馈阶段 —— 看结果
- 顶部 HUD 实时显示：年份、人口、国库、平均满意度、智力、罪犯数
- 中间饼图与曲线呈现阶级人口与历史趋势
- 右侧「朝堂日志」记录这一年发生的所有事情
- 触发事件时会弹窗，必须做出选择才能进入下一年

## 三、四个阶级，两种物品

### 物品
- **粮食**：所有人吃饭、缴税、当货币
- **产品**：工人生产，提升生活满意度

### 阶级
| 阶级 | 颜色 | 角色 |
|---|---|---|
| 农民 🌾 | 绿 | 生产粮食，购买产品 |
| 工人 🏭 | 蓝 | 生产产品，购买粮食 |
| 商人 💰 | 金 | 撮合产品流通，赚差价 |
| 公务员 ⚖ | 紫 | 收税 / 治安 / 教育 / 国防 |

智力高的人有概率向上一阶级流动；连续亏损的人会向下一阶级跌落；满意度过低会变成罪犯，过高会变成"膨胀者"，两者都拒绝交税与劳动。

---

## 四、事件系统

游戏内已实现 8 张事件卡：

| 事件 | 触发 | 备注 |
|---|---|---|
| 蝗灾来袭 | 第 7、14、21… 年 | 测验你赈灾决心 |
| 商队来访 | 商人 ≥ 2 | 高税 vs 低税 |
| 学子上书 | 智力均值 > 55 | 是否开科举 |
| 风调雨顺 | 第 2 年起随机 | 加征 vs 藏富 |
| 流民聚众 | 罪犯出现时 | 武力 vs 安抚 |
| 瘟疫蔓延 | 第 5 年 + 人口≥30 | 钱包 vs 人命 |
| 邻国联姻 | 第 8 年起 | 政治外交 |
| 通货膨胀 | 商人富过农民 3 倍 | 阶级抉择 |

每个事件都没有「最优解」，必须在两个负面或两个权衡里取其一。

---

## 五、胜负条件

### 失败（任一即结束）
- 国库破产 ≥ 3 年
- 总人口归零
- 罪犯占比 > 30%

### 胜利（按章节）
| 章节 | 时长 | 目标 |
|---|---|---|
| 立国 | 5 年 | 平均满意度 ≥ 5 |
| 兴邦 | 20 年 | 国库 ≥ 5000 且人口 ≥ 200 |
| 治世 | 50 年 | 智力均值 ≥ 70 |
| 盛世 | 100 年 | 三个阶级满意度全 ≥ 10 |

> 当前 v0.1 仅开放章节 1（立国）。

## 六、操作清单

### Web 版
- 鼠标拖动滑块调政策
- 点击右下"⏯ 下一年"推进回合
- 顶部按钮：💾 存档 / 📂 读档 / 🔄 重开
- 事件弹窗：直接点选项

### 小程序版
- 底部 TabBar：执政 / 政策 / 关于
- 政策页拖动滑块
- 执政页"⏯ 下一年"

## 七、新手 5 条心法

1. **第 1 年不要慌**，先点"下一年"看看默认数值能跑成什么样
2. **税率不是越高越好**：高税收能填国库，但会让满意度暴跌
3. **教师是隐形最强**：每个教师每年给 10 个学生加智力，长期回报巨大
4. **治安官只在乱世有用**：太平时是负担，乱世救命
5. **事件没有标准答案**，每张卡都在考验你"舍什么"

## 八、可视化解读

- **饼图**：四种颜色分别是 农 / 工 / 商 / 公 的人口占比
- **历史曲线**：蓝=人口，绿=平均满意度，金=国库
- **HUD 罪犯数**为红色，超过 10% 就要小心了
