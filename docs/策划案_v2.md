# 《小国执政官》策划案 v2.0

> 本文档是在原始 v1 基础上，由资深游戏策划复盘后输出的改进版本。
> 原始 v1 文档保留于仓库根目录的 `原始策划案/` 下作历史档案。

---

## 0. 一句话定位

> **「数值模拟版的《王权》× 缩小版的《Tropico》× 极简水墨风的《文明》。」**
> 玩家扮演新上任的执政官，用「调税收 / 设官员 / 推政策 / 处理事件」四种动作，让一个 100~1000 人的小国活下去并繁荣。

---

## 1. 核心信息

| 项 | 内容 |
|---|---|
| 游戏类型 | 回合制经济社会模拟 SLG（轻量化、单局 15~30 分钟） |
| 视角 | 上帝视角，2D 数据可视化 + 极简插画 |
| 平台 | Web（GitHub Pages） + 微信小程序，未来可扩 iOS/Android |
| 目标用户 | 16~40 岁男性为主，喜欢策略 / 模拟经营 / 数值博弈，参考《了不起的修仙模拟器》《人类一败涂地》《王权》玩家群 |
| 美术风格 | 中式水墨 + 现代极简信息图，主色 #2c3e50 / #c0392b / #f1c40f |
| 引擎 | 原生 JS + Canvas（无构建依赖），便于双端复用 |
| 商业化 | 免费 + 关卡 DLC + 皮肤主题（小程序内激励视频解锁皮肤） |

## 2. 核心循环 Game Loop

每一**年**为一回合，单回合时长 30 秒~2 分钟：

```
┌─────────────────────────────────────────────┐
│ ① 决策阶段（玩家可操作）                     │
│   - 调整税率（农 / 工 / 商）                  │
│   - 调整公务员配额（治安 / 教育 / 民生 / 军事）│
│   - 处理弹窗事件（旱灾 / 起义 / 联姻 ……）     │
│   - 颁布临时政策（赈灾 / 戒严 / 开科举 ……）   │
├─────────────────────────────────────────────┤
│ ② 结算阶段（自动模拟，~1s 动画）              │
│   按 v1 设定的「结算顺序」12 步跑一遍         │
├─────────────────────────────────────────────┤
│ ③ 反馈阶段                                   │
│   - 年度总结弹窗（人口/GDP/满意度/国库变化）  │
│   - 历史曲线刷新                              │
│   - 触发剧情节点 / 成就                       │
└─────────────────────────────────────────────┘
                    ↓
              进入下一年
```

## 3. 胜负条件 & 目标系统（v1 缺失）

### 3.1 失败条件（任一即结束）
- **国库破产**：国库粮食 < 0 且持续 3 年
- **人口归零**：总人口 = 0
- **革命爆发**：罪犯比例 > 30% 持续 2 年
- **执政官下台**：平均满意度 < -5 持续 5 年

### 3.2 关卡式胜利目标（章节制）

| 章节 | 名称 | 起始 | 胜利条件 | 解锁奖励 |
|---|---|---|---|---|
| 1 | 立国 | 25 人 / 5 年存活 | 平均满意度 ≥ 5 | 教育官员 |
| 2 | 兴邦 | 100 人 / 20 年 | 国库 ≥ 5000、人口 ≥ 200 | 商业政策 |
| 3 | 治世 | 200 人 / 50 年 | 智力均值 ≥ 70 | 军事官员 |
| 4 | 盛世 | 500 人 / 100 年 | 三个阶级满意度全 ≥ 10 | 「永恒模式」 |
| ∞ | 沙盒 | 自定义 | 无 | 自由调控 |

## 4. 角色与阶级（沿用 v1，做规模化）

| 阶级 | 身份 | 生产 | 默认人数（章节 1） |
|---|---|---|---|
| 农民 | 第一产业 | 粮食 13/年/人（受智力 ±20% 浮动） | 10 |
| 工人 | 第二产业 | 产品 20/年/人 | 5 |
| 商人 | 第三产业 | 中介买卖、抽佣 | 2 |
| 公务员 | 政府 | 收税 / 治安 / 教育 / 国防 | 8（含总督 1） |

公务员细分（v1 已有，本次明确数值上限）：
- 税务官：每 10 农村人 / 10 城市人 各需 1 人
- 治安官：每人可制服 1 个罪犯影响
- 民生官：可压低产品上限价 5%
- 军事官：可调拨国库 0~50% 作军费
- 教师：1 师 = 10 学生，每年 +0.25 智力（封顶 +5）、满意度 +0.5
- 总督：隐性，统筹国库

## 5. 数值系统（修复 v1 公式 bug）

> 原始 v1 公式有边界问题，v2 给出可直接落地的版本。

### 5.1 满意度增减
```js
// 粮食满足度
if (grain < demand)              dS = -5;
else if (grain < demand+reserve) dS = -2;
else                              dS = +0.2;  // 新增正反馈

// 产品满足度
if (product < 2)                  dS -= 5;
else if (product < 4)             dS -= 1.5;

// 阶级财富落差（v1 公式形式保留，但参数收口）
const d = avgWealth_richest - avgWealth_poorest;
const fs = 2*Math.atan(1.8) + 2*Math.atan(2*d - 1.8);  // 把 18 改为 1.8 防爆炸
satisfactionPenaltyForPoorest -= clamp(fs, 0, 8);
```

### 5.2 死亡率（修复除零）
```js
// 50 岁起开始有死亡概率
function deathProb(age){
  if (age < 50) return 0;
  if (age >= 90) return 1;
  return 1 - 1/Math.max(age-49, 1);   // 原 1/(x-49) 在 x=49 时除零
}
```

### 5.3 产品需求（限制非负）
```js
function productDemand(s){
  const a1 = 12, a2 = 15;
  return Math.max(0, -(s-a1)*(s-a2) + 2);
}
```

### 5.4 性能：人口 > 200 时降级为「桶模拟」
- ≤ 200 人：逐人模拟（O(n)）
- > 200 人：按「阶级 × 财富分位」分 12 个桶，桶内取均值（O(桶数)）

## 6. 事件系统（v1 完全缺失）

事件库 ≥ 30 张卡，按权重随机抽取：

| 类型 | 示例 | 触发条件 | 选项（影响） |
|---|---|---|---|
| 自然 | 蝗灾 | 第 3 年起 5% | A 开仓赈灾(国库-200) / B 听天由命(满意度-3) |
| 经济 | 商队来访 | 商人≥3 | A 高税(国库+100/满意度-1) / B 低税(国库+20/满意度+2) |
| 社会 | 学子上书 | 智力均值>60 | A 开科举(智力+1) / B 拒绝(满意度-2) |
| 军事 | 邻国挑衅 | 章节3+ | A 备战(国库-500) / B 议和(每年-50) / C 开战(随机) |
| 剧情 | 旧臣谋反 | 满意度<-3 | 触发后立即一次掠夺事件 |

事件设计规范：每张卡至少 2 个选项；选项之间没有显然最优；后果在 1~3 年内可见。

## 8. 新手引导（v1 缺失）

3 步引导（首次进入触发）：
1. **第 1 年**：高亮"下一年"按钮，引导玩家直接结算，看一遍数据
2. **第 2 年**：高亮"农民税率"，引导调到 5%
3. **第 3 年**：触发「旱灾」事件卡，引导玩家做选择
